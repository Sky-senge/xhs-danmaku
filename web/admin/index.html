采集控制

插件不会去破解小红书的签名，而是旁听真实客户端自己的弹幕长连接：要么接管「小红书直播助手」， 要么开一个真实 Chrome 打开能看见弹幕的网页。两条路走的是同一个通道，解析代码完全一样。

普通用户用这个就行。插件会自己拉起「小红书直播助手」，从 App 自己的弹幕长连接里读消息—— 不需要中控台权限，也不用再扫一次码（用的是 App 里已登录的账号）。 如果 App 现在正开着，请先完全退出（右键托盘图标 → 退出），再点右上角「启动采集」。 万一插件拉不起来（没弹 UAC、或点了「否」），双击项目里的 start-helper-debug.cmd， 再回来点一次「启动采集」就能接上。

方舟是商家（店铺）后台，普通个人账号登进去可能只看到招商 / 入驻页面；达人直播在 蒲公英；如果你用「小红书直播助手」开播、App 里就能看弹幕，那就打开自己的直播间页面即可。 拿不准也没关系：启动后在弹出的窗口里自己点进能看见弹幕的页面，插件会自动接上任何标签页里的弹幕通道。

怎么开播都能用

推流方式和弹幕采集无关：你用 OBS 直接推、用「小红书直播助手」推，都走同一条弹幕通道。 下面按数据源分成两种，插件会自动按你选的走。

1先把「小红书直播助手」完全退出（含托盘图标），插件要自己带调试端口把它拉起来
2点右上角「启动采集」，插件会自动打开直播助手，并接上它的弹幕长连接
3在 App 里登录、开播；状态变成「接收中」后右侧预览就会滚起来
4把 OBS 地址填进 OBS 的「浏览器」源，宽度 800、高度 1000
1点右上角「启动采集」，会弹出一个 Chrome 窗口
2在该窗口登录小红书（商家登方舟、达人登蒲公英），进入能看见弹幕的页面
3状态变成「接收中」后，右侧预览就会开始滚动弹幕
4把 OBS 地址填进 OBS 的「浏览器」源，宽度 800、高度 1000

语音播报

把弹幕念出来。声音由弹幕层页面（OBS 浏览器源）发出，记得在 OBS 里勾选「通过 OBS 控制音频」， 否则混音器里不会有这一路声音。

语速与节奏

直播高峰一秒好几条，念不完就丢掉后面的，保证念到的是「现在」的弹幕。

试听

试听会走完整的合成流程，能听到就说明网络和音色都没问题。

比如把「关注了主播」改成「新朋友关注」，会立刻反映到画面上。

状态角标

画面右下角显示「已连接 / 断线」，正式推流前记得关掉。

过滤与防刷屏

被过滤掉的消息不会出现在弹幕层，也不会进入统计。

自定义 CSS

追加到弹幕层页面，可以覆盖任何样式。改错了点「恢复默认」即可。

配置备份

换电脑或者调好一套想留着，导出成 JSON；以后导入回来即可。

原始帧调试

协议变了、或者事件没出来时看这里。若出现大量「未知 type」，把 type 名字记下来就能补上映射。
